# Vertex

Vertex is a learning platform in development. The current application shows the homepage at `/` and the design-system reference at `/design-system`.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npx tsc --noEmit
npm run lint
npm run build
```

Inter and Playfair Display are self-hosted in `public/fonts/`; their license notices are included there.
