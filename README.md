# Vertex

Vertex is a learning platform in development. The current application contains the design-system reference page at `/`, based on the supplied Vertex design image.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npx tsc --noEmit
npm run lint
npm run build
```

Inter and Playfair Display are self-hosted in `public/fonts/`; their license notices are included there.
