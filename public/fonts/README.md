# Vertex fonts

The design system self-hosts two variable fonts from the official [Google Fonts repository](https://github.com/google/fonts):

- [Inter](https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf) — `Inter.ttf`
- [Playfair Display](https://github.com/google/fonts/blob/main/ofl/playfairdisplay/PlayfairDisplay%5Bwght%5D.ttf) — `PlayfairDisplay.ttf`

Both are distributed under the SIL Open Font License 1.1. The corresponding notices are in `OFL-Inter.txt` and `OFL-PlayfairDisplay.txt`.
